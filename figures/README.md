# Figures

These are the principal visual outputs from the final notebook.

| File | Description |
|---|---|
| `feature_noise_f1.png` | F1-score across feature-noise levels for Logistic Regression and KNN |
| `label_noise_f1.png` | F1-score across label-noise levels for both models |
| `label_noise_auc.png` | ROC-AUC across label-noise levels |
| `pulsar_survival.png` | Survival of original pulsar labels under symmetric label noise |
| `confusion_matrix_knn_10pct_label_noise.png` | KNN confusion matrix at 10% label noise |
| `confusion_matrix_logreg_10pct_label_noise.png` | Logistic Regression confusion matrix at 10% label noise |

### Purpose

The F1 figures show performance degradation. ROC-AUC provides a complementary ranking-based view. The pulsar-survival figure explains how the label-noise mechanism progressively corrupts the minority-class signal. The two confusion matrices show TP, TN, FP and FN at the strongest tested label-noise condition.

### Reproducibility

All figures are generated by the final notebook. Re-run the notebook rather than manually editing the images.
