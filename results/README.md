# Results

This directory stores machine-readable outputs generated by the final notebook.

## Recommended files

| File | Contents |
|---|---|
| `feature_noise_results.csv` | Per-repetition metrics for feature-noise conditions |
| `label_noise_results.csv` | Per-repetition metrics for label-noise conditions |
| `transition_results.csv` | Detailed 6–10% label-noise transition results |
| `summary_tables.csv` | Aggregated tables used for reporting |

If the final notebook generates different filenames, keep the notebook's actual filenames rather than renaming them manually.

## Metrics

The experiments record:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

Transition results additionally contain confusion-matrix counts and minority-class diagnostics.

## Reproducibility

The CSV files should be generated by running the final notebook from a fresh runtime. The notebook is the authoritative source for the numerical results.
